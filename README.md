The Moodle Mobile App is an iOS application developed using SwiftUI that connects to a Moodle-based Learning Management System (LMS).
The app allows students to log in, browse courses, view grades, and access course content through Moodle Web Services APIs.
This project was created as an assignment to demonstrate:
API integration
JSON decoding
MVVM architecture
SwiftUI UI development
Networking in iOS
Error handling and asynchronous data loading
🚀 Features
📚 Courses Screen
Fetch enrolled courses from Moodle API
Display course names and summaries
Scrollable modern SwiftUI interface
📊 Grades Screen
Retrieve grades for enrolled courses
Show course items and grades dynamically
Decode nested JSON responses
🎨 UI & Navigation
Built entirely using SwiftUI
NavigationStack-based navigation
Custom orange navigation bar theme
White navigation back button styling
⚠️ Error Handling
Handles API failures gracefully
Displays loading states and decoding errors
🛠️ Technologies Used
Swift
SwiftUI
MVVM Architecture
URLSession
Codable
Moodle REST API
